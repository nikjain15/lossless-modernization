## Notes for Claude Code

This is a prose playbook, not a codebase: there is nothing to build, run, or test. Two style rules are non-negotiable and easy to violate while drafting: never use an em dash, and never use a spaced hyphen as a sentence separator. Rewrite with commas, colons, or periods instead. Compound-word hyphens such as event-driven and real-time are fine. Before finishing, scan any file you touched for both.
